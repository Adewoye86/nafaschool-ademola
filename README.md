# NafaSchool Project

## (a) The Problem
Schools need an automated, clear, and reliable system to manage pupil fee structures, track installment payments, and calculate outstanding balances accurately without manual record errors.

## (b) The User (Mariama)
Mariama is a school administrative and finance officer responsible for managing student fee records, tracking installment payments, verifying balance statuses, and issuing clear financial updates to parents.

## (c) Out-of-Scope Items
- Live real-time payment gateway integration (e.g., Stripe, Paystack).
- Multi-currency conversion engines.
- Parent-facing mobile application user interfaces.
- Automated SMS/email billing notification dispatch system.
